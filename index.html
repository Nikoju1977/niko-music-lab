GUIDE INTÉGRÉ

Prise en main

1. Démarrer : appuyez sur ▶, puis choisissez Techno, EBM, Acid, House ou Drum & Bass pour charger un rythme original.

2. Programmer : touchez les cases du séquenceur. Maj + clic ou appui prolongé accentue une note.

3. Composer : utilisez Piano roll pour écrire les notes de basse, de lead et de pad. Passez d'un pattern A à D.

4. Arranger : dans Arrangement, attribuez les patterns à chaque mesure. Activez « Morceau » pour écouter la structure.

5. Mixer : réglez les volumes, panoramiques, filtres et effets. Les pistes « Solo » prennent la priorité.

6. Importer : ouvrez une piste SAMPLE et chargez WAV/MP3/OGG/M4A pris en charge par votre navigateur. Le micro peut aussi être enregistré.

7. Exporter : WAV pour écouter/mixer ; MIDI pour un autre DAW ; PROJET JSON pour rouvrir la session.

Raccourcis : Espace = lecture/pause ; Échap = fermer les fenêtres. Sur mobile, un premier appui sur ▶ autorise la lecture audio.
